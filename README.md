# A Little Surprise 🌸

A romantic, interactive website built with pure HTML, CSS, and JavaScript. Features beautiful glassmorphism design, aurora animations, floating petals, and a heartfelt question.

## Features

- ✨ Animated aurora background
- 🌸 Floating sakura petals and fireflies
- ⭐ Twinkling stars
- 🎵 Background music toggle
- 💖 Confetti, fireworks, and heart rain
- 😂 Funny animated cards
- 🎮 Interactive dodging button
- 📱 Fully responsive design
- 🖱️ Cursor glow effect

## How to Use

1. Open `index.html` in any modern web browser
2. Watch the loading screen
3. Click "Continue 🌸" to proceed through the story
4. Enjoy the animations and surprises!

## Project Structure

```
├── index.html       # Main HTML file
├── style.css        # All styles and animations
├── script.js        # Interactivity and effects
├── assets/
│   ├── flowers/     # Flower images (optional)
│   ├── memes/       # Meme images (optional)
│   ├── music/       # Background music (add piano.mp3)
│   └── icons/       # Custom icons (optional)
└── README.md
```

## Customization

Edit the following in the code to personalize:

- **Colors**: Change CSS variables in `style.css` under `:root`
- **Text**: Edit text content in `index.html`
- **Music**: Replace `assets/music/piano.mp3` with your own audio file
- **Animations**: Adjust timing and styles in `style.css`

## Browser Support

Works best in modern browsers: Chrome, Firefox, Safari, Edge.
